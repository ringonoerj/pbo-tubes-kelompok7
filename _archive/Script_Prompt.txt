# SMARTCASHIER - SPESIFIKASI PROTOTIPE APLIKASI

## 🎯 GOAL UTAMA
Membuat web aplikasi kasir SMARTCASHIER berbasis Java dengan kode yang paling sederhana namun fungsional, diawali dengan pemeriksaan kesiapan lingkungan/aplikasi penunjang secara otomatis dan menginstalnya jika belum siap.

---

## 🛠️ BAGIAN 1: PEMERIKSAAN & INSTALASI APLIKASI PENUNJANG (PREREQUISITES)

Sebelum kode aplikasi dikembangkan atau dijalankan, sistem/script harus memeriksa kesiapan software berikut:

| Komponen | Versi Minimal | Metode Pemeriksaan | Tindakan Jika Belum Siap |
|----------|---------------|-------------------|---------------------------|
| **Java JDK** | 17 | `java -version` atau cek `$env:JAVA_HOME` | Unduh & install OpenJDK 17 via Winget/Chocolatey |
| **PostgreSQL** | 14 | Cek service `postgresql` atau port `5432` | Install PostgreSQL 14/17 via Chocolatey (`choco install postgresql14 --params "/Password:postgres" -y`) |
| **Node.js & NPM**| 18.x / 9.x | `node -v` dan `npm -v` | Install Node.js via Winget/Chocolatey |
| **Apache Maven** | 3.x | `mvn -version` | Install Maven via Chocolatey (`choco install maven -y`) |

**Alur Otomatisasi:**
1. Deteksi semua software di atas menggunakan script Windows PowerShell.
2. Jika ada software yang tidak terdeteksi, jalankan instalasi otomatis secara silent (unattended) dengan hak akses administrator (elevated).

## 💻 BAGIAN 2: PENGEMBANGAN APLIKASI WEB JAVA SEDERHANA

Aplikasi web dikembangkan menggunakan struktur Java Spring Boot yang paling minimalis dan sederhana (minimal boilerplate) dengan frontend React.js.

### 📁 KODE BASIS JAVA (WAJIB DIPERHAHANKAN)

1. **User.java (Abstract Class)**
```java
package smartcashier.entity;

public abstract class User {
    protected String id;
    protected String name;
    protected String phoneNumber;

    public User(String id, String name, String phoneNumber) {
        this.id = id;
        this.name = name;
        this.phoneNumber = phoneNumber;
    }

    public abstract void displayProfile();
    public String getId() { return this.id; }
    public String getName() { return this.name; }
    public String getPhoneNumber() { return this.phoneNumber; }
}
```

2. **Karyawan.java (Extends User)**
```java
package smartcashier.entity;

public class Karyawan extends User {
    private String employeeId;
    private String password;
    private double kpiScore;

    public Karyawan(String id, String name, String phoneNumber, String password) {
        super(id, name, phoneNumber);
        this.employeeId = id;
        this.password = password;
        this.kpiScore = 0.0;
    }

    public boolean login(String inputId, String inputPassword) {
        return this.employeeId.equals(inputId) && this.password.equals(inputPassword);
    }

    public double getKpi() { return this.kpiScore; }
    public void addKpi(double score) { this.kpiScore += score; }

    @Override
    public void displayProfile() {
        System.out.println("ID Karyawan : " + this.employeeId);
        System.out.println("Nama        : " + this.name);
        System.out.println("KPI         : " + this.kpiScore);
    }
}
```

### ⚙️ PENYEDERHANAAN KODE JAVA (SIMPLIFIED WEB APP)
* Gunakan JPA Entity yang langsung memetakan kelas ke tabel database PostgreSQL `smartcashier_db`.
* Implementasikan logic transaksi sederhana:
  * **CalculatorTools.java**: berisi static methods `add`, `subtract`, `multiply`, `divide` untuk menghitung diskon member (5%) dan total belanja.
  * **Transaction.java**: menyimpan id transaksi, kasir yang bertugas, member (jika ada), total belanja, dan list barang.
* Sediakan REST Controller minimalis agar dapat dikonsumsi oleh UI React.
